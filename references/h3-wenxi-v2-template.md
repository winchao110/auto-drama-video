# MiniMax H3 5–15 秒文戏｜版本2 完整 Markdown 提示词模板（融合 AI 漫剧公司导演写法）

本模板 = 版本1的 H3 格式骨架（Subject/S 编号、声线、画外音限制、Shot 结构、固定尾部、默认中文） + 《AI 漫剧公司导演提示词指南》的电影级增强（画质前置、运镜公式、光影套件、音频设计）。

适用于：

- 剧本流：根据小说、剧本或对白拆分并生成提示词；
- 单图流：根据一张人物图或双人合照推演剧情与台词。

## 零、本技能覆盖条款（优先级高于本模板任何写法）

自 2026-10-19 起，`auto-drama-video` 的输出格式**整体换成六段式**（不是本模板的中文小标题段落流）：

```text
subject_definitions:
summary:
retention_analysis:
detailed_description:
overall_soundscape:
non_diegetic_music:
```

`subject_definitions` 写 Subject/Audio 对应关系与开场站位，`detailed_description` 首句写全局风格 + 画幅 + 禁止项，
其后每镜一个 `[Shot N]`（**不写 `At 00:03.000` 之类时长**）。完整字段与断段规则见 `01-h3-prompt-bilingual.md` 的 2.1 / 2.2。

在此基础上，用下面五条覆盖本模板中所有冲突写法（完整版见 `01-h3-prompt-bilingual.md` 的「四之三」）：

| # | 覆盖内容 |
|---|---|
| A | **画幅决定同框**：宽屏（16:9 / 21:9 / 4:3）可以两人同框；**窄屏（9:16 / 3:4）一律禁止两人同框**，一人一镜、正反打接。 |
| B | **优先过脸 / 过肩 / 过腰的关系镜头**，每个 Shot 都要交代前景与后景；说话或做动作的人在焦点上，对手只作前景轮廓。 |
| C | **每段独立**：ComfyUI 逐段生成、没有上文记忆。禁止 `still / remains / as before / 仍然 / 如前`；每段场景段必须重写"本段开场站位与姿势"。 |
| D | **Shot 不写光影**（模板里所有 `[光影微调]` 槽位一律不填），全局光影只在场景段写一次；**人物没移动就不写画面位置**，移动时必须写 `from…to…` 且起点与本段开场状态一致。 |
| E | **Shot 里不写时长**：所有 `[0-3秒]`、`At 00:03.000` 一律不写，镜头长短交回模型；段总时长仍由 `sec` / `genSec` 控制。 |
| F | **去掉 `【禁止项】` / `【强制声明】` 尾部块**（下文第 10、11 条与所有示例里的这两块作废），禁止项并进 `detailed_description:` 首句。 |

读下文时：`[分镜专属光影微调]`、`[光影微调]`、`要求各镜总时长` 视为**已废弃**；`[人物画面位置]` 只在场景段的开场站位句里用一次，
不进 `[Shot]`。第「4.4 影视光影套件」仍然可用，但只用它给整段定一套全局光影。

## 一、填写规则（沿用版本1，含导演融合调整）

1. 把所有 `[方括号占位内容]` 替换为实际内容。
2. 人名一律使用剧本/原作的**中文原名**（如 `陈硕`、`沈若晴`），不转拼音、不音译英文。中文名直接写在 `<Subject1>`、`<Subject2>` 与各 `[Shot]` 的人物位置描述中。
3. 单人画面只保留 Subject1/S1，核心台词只允许这一人说。
4. 主要说话人最多两名，分别绑定 Subject1/S1 与 Subject2/S2。一次性功能角色可保留一句 ≤20 字临时环境人声，不建声线、不与主要角色同时说话、不延续。
5. 两人出现在同一张图时，都绑定 `<Picture 1>`，用左右位置、发型、服装区分；两人各有独立参考图时分别绑定 `<Picture 1>`、`<Picture 2>`。
6. 每个 `[Shot N]` 必须独占一行，镜头内容从下一行开始，并**按导演运镜公式书写**（见"二、导演增强"）。
7. 画内台词严格两行：

```text
<Subject 1> (S1) says:
<d>[Chinese]台词</d>
```

8. 只有当前场景存在两名及以上已绑定人物时，才允许画外音；已绑定角色画外音严格三行：

```text
画外音
<Subject 1> (S1) says:
<d>[Chinese]台词</d>
```

9. `画外音` 不加冒号、人物名、"继续"或可见性解释。单人场景禁止画外音。
10. 单元标题是提示词外的管理信息；复制到 MiniMax 时，从**全局画质与摄影前置块**开始，随后是第一条 `<Subject1>`，到该单元【强制声明】结束。
11. 【禁止项】和【强制声明】必须逐字保留。
12. 场景声明 `<Subject N>是[场景名称]场景。` 必须保留在角色与声线块之后、`[Shot 1]` 之前；**不设独立的"人物站位"段**，但场景声明之后必须紧跟一句**本段开场站位与姿势**（谁在哪、坐/站/靠/躺、手里有什么、朝向谁），Shot 里不再重复位置（人物移动时写 `from…to…`），避免模型把站位渲染成开场远景人物镜头。
13. 每个单元只写入本段实际出场的人物 `<Subject>`；某角色在本段完全没有出场时，不把他的 `<Subject>` 写进该段。
14. **参考图最小化（硬规则，防止画面污染）**：每段只上传本段实际出场人物（有台词、或需要清晰面部反应/近景）的参考图；本段不出场人物的参考图必须从 MiniMax 上传位撤下，不要一起传。多余的参考图会让模型误以为该角色会出现在画面里，导致串脸、凭空多出人、面部特征污染。**Picture 编号在本段内从 `<Picture 1>` 开始连续重排，不沿用全局编号**；段与段之间 Picture 编号相互独立。纯背景虚化人影不要求面部一致性时，不传参考图，Shot 描述里写"旁边人影虚化/不可辨"即可。

## 二、生成前引导流程

### 1. 完整读取与信息分流（同版本1）

- 完整读取小说、剧本、对白、人物设定、时间码和参考图；保留人物关系、事件顺序、关键台词、核心道具和情绪落点。
- 信息分四类：画内台词；OS/内心声/画外延续（两人及以上→绑定角色画外音，单人→低声自语）；临时功能人声；字幕/论坛/聊天/片名/时间文字（移至后期，不要求模型生成）。
- 原作时间码只表示叙事意图；与自然表演或 5–15 秒上限冲突时重新估时。

### 2. 划分 5–15 秒单元（同版本1）

每个单元只承载：一个主场景、一次微型关系变化、一条主动作链、一个明确出口。先标硬边界，相邻边界间按剧情自然长度定时长（5–15 秒）。合并后超 48 字、出现两条独立主动作链、或表演放不下时才拆开。反向检查：把"问句+回答+眼神/反应"合并进同一单元，严禁单句反应/一次眼神/离场台词/转场画外音单独占段。

### 3. 台词预算与 Shot 密度（同版本1）

| 目标时长 | 建议台词 | 建议 Shot 数 |
|---|---:|---:|
| 5 秒 | 12–18 字 | 1–2 个 |
| 8 秒 | 20–28 字 | 2–3 个 |
| 10 秒 | 24–32 字 | 2–3 个 |
| 12 秒 | 32–40 字 | 3–4 个 |
| 15 秒 | 40–48 字 | 3–5 个 |

52 字是紧凑语速硬上限。每段只保留一条"启动→回应→结果"主动作链；倾听者须对具体台词有可见反应。

### 4. 导演增强（本技能核心增量，版本1无此部分）

#### 4.1 全局基础画质前置词

每个单元正文开头（`<Subject1>` 之前）放置画质与摄影前置块，随正文一起复制：

- **【分辨率】** 8K 超高清院线电影级画质，超高细节纹理，4K 渲染输出
- **【摄影机】** ARRI Alexa 65 大画幅电影机质感，动态宽密度拉满
- **【镜头】** 50mm 标准定焦镜头，f/2.8 浅景深，焦点精准锁定人物主体
- **【胶片质感】（可选）** 柯达 5219 电影胶片，细腻自然颗粒，色彩柔和
- **【制式标准】** 24fps 标准电影帧率，2.39:1 宽银幕画幅（文戏双人对白如需贴近平实，可改 16:9）
- **【全局硬性约束】** 全程无超帧、无画面畸变扭曲、无多余空镜、无穿帮道具，人物口型与台词精准同步；无 AI 失真脸部，皮肤保留原生毛孔肌理，拒绝过度磨皮、重度美白；人物四肢手部动作自然无畸形，五官脸型全程统一，服装发型配饰前后镜头无改动；画面流畅无抖动、无闪烁卡顿、无崩坏肢体
- **【真人专属补充】（真人类角色可选）** 真实亚洲人种皮肤质感，自然面部微表情，毛细血管细微可见，阴影过渡柔和，无塑料假人质感

#### 4.2 漫剧风格（可选，用户要求某风格时写入画质前置块尾部）

- **韩漫**：韩漫 manhwa webtoon 风格，清晰钢笔线条，平涂上色，分层柔和
- **日漫**：吉卜力手绘风 / 新海诚光影风 / 赛璐璐复古古风
- **国漫**：东方水墨风 / 3A 游戏 CG 厚涂风

#### 4.3 分镜运镜公式（每个 `[Shot N]` 必须按此公式书写）

**公式结构：**
`[运镜方式]+[景别]+[人物画面位置与主体描述]+[连贯动作链条]+[场景环境细节]+[分镜专属光影微调]`

**Shot 内不写时间码（硬规则）**：不要在 Shot 描述里出现 `[0-X秒]`、`[0-3秒]`、`[3-7秒]` 之类的时间区间。整段总时长在单元标题里声明即可，每个 Shot 持续几秒、节奏松紧交给模型自己发挥；写死时间码会绑死模型、破坏自然表演节奏。

**运镜词库（从下拉选一个）**：固定机位（带轻微自然呼吸抖动）/ 缓慢匀速向前推进 / 缓慢匀速向后拉开 / 水平左右横移 / 垂直上下摇摄 / 360° 缓慢环绕镜头 / 斯坦尼康跟拍。

**景别词库（选一个）**：特写（面部/手部）/ 近景（胸口以上）/ 中景（腰部以上）/ 中全景（全身+近景环境）/ 远景（大环境全景）。

**示例**：
> 固定机位，近景，人物位于画面左侧，低头凝视掌心，指尖微微颤抖；背景街道灯光虚化，分镜光影：侧方冷蓝路灯打亮侧脸，暗部保留层次。
> 缓慢匀速向前推进，从中景缓缓推至面部特写，人物缓缓抬头望向远处，眼底落寞慢慢泛红；背景灯光逐渐虚化失焦。

> 融合到 H3 时，把台词放到对应 Shot 的 `says:` 后，动作链与光影微调写在镜头描述内。

#### 4.4 影视光影套件（每个单元指定一套"全局光影"，并写进各 Shot 光影微调）

**光影通用公式**：`[主光源类型]+[精准色温]+[光线投射方向]+[辅光/轮廓光搭配]+[聚焦区域]+[明暗对比度]+[整体情绪氛围]`

**成套光影（按情绪选一套）**：

1. **伦勃朗光**（单人情绪/悬疑/文艺）：全局光影：单侧硬光主灯+弱辅光，人物脸颊形成标志性三角光斑，后方窄轮廓光分离背景，色温 4200K，光线聚焦人物面部，明暗层次分明，氛围压抑伤感。
2. **蝴蝶光**（甜宠温柔女主）：全局光影：正面高位柔光主灯，下方反光板弱化暗部阴影，色温 5500K，柔和低对比，整体治愈温柔氛围。
3. **黄昏侧逆光**（离别/黄金时刻）：全局光影：夕阳暖调侧逆光，色温 3200K，强发丝轮廓光，正面低亮度柔光辅光，冷暖撞色，温柔伤感氛围。
4. **三点柔光**（日常居家/办公室对话）：全局光影：正面柔光主光+侧辅光+背部轮廓光，色温 5500K，明暗过渡平缓，日常松弛治愈氛围。
5. **悬疑单硬光**（密室对峙/惊悚）：全局光影：顶部单侧硬光主光源，色温 4000K，无多余辅光，极高明暗对比，大面积深邃暗部，紧张压抑悬疑氛围。
6. **蓝调城市夜景光**（都市孤独戏份）：全局光影：天空冷蓝环境光 7000K，搭配街边暖黄辅光，伦勃朗光塑造人物面部，冷暖对冲，孤独压抑氛围。
7. **煤油暖黄光**（夜晚室内离别戏）：全局光影：单盏煤油灯侧方暖黄主光，色温 2600K，低亮度辅光提亮眼窝，面部形成伦勃朗三角光斑，厚重沉郁离别氛围。
8. **赛博朋克对比光**（霓虹都市/科幻）：全局光影：红蓝双色霓虹分侧对冲打光，混合色温，低亮度环境，高色彩反差，赛博氛围感。

#### 4.5 音频设计模板（可选增强）

默认与固定尾部"无背景音乐，仅保留环境音与人声和音效"一致。用户要求更细的音频时，按公式补充：

**音频标准公式**：`[持续环境音（音量 dB）]+[定点关键音效（出现时间+音量 dB）]+[背景音乐（曲风+音量 dB，默认无）+[人声约束]`

**素材库**：环境音=持续雨声/晚风/街道车流杂音/室内安静底噪/森林风声；关键音效=脚步声/开门声/纸张撕裂声/雨滴砸玻璃/金属碰撞/心跳声；背景音乐=低沉钢琴独奏/舒缓弦乐/氛围感电子合成器/无背景音乐。

**示例**：> 音频设计：持续细密雨声（-12dB），2 秒处加入纸张撕开清脆音效（-6dB），全程背景音乐为低沉舒缓钢琴独奏（-18dB），无多余杂音，人物对白人声清晰突出，音效不盖过人声。

## 八、可爱轻喜剧 Shot 结构（同版本1，Shot 描述套用运镜公式）

适用于番茄、杯子、食物、礼物、宠物玩具等图片中已经存在的道具：

```text

<d>[Chinese][带一点自信或期待的台词]</d>

[Shot 2]
[运镜方式]，[人物或手部近景]，[人物轻轻尝试、触碰、打开、转动或移动道具]。[道具出现小意外或判断被证伪]。

[Shot 3]
```

## 九、拥抱与亲吻 Shot 替换块（同版本1）

仅在用户明确要求、双方均为成年人且关系允许时，用下方结构替换最后一个 Shot。开始前必须从上一 Shot 的人物距离和道具状态启动。

```text
[Shot 5]
[运镜方式]，[主动方]先把手中的[包/杯子/手机/其他道具]放到[明确位置]或挂到[手臂位置]，随后通过[一步或连续可见移动]缩短两人之间的距离。[主动方]双臂环住[另一方的腰/后背]完成拥抱；[另一方]先出现由突然靠近触发的短暂反应，随后一只手环住[主动方]后背，另一只手扶住[肩侧/手臂]完成回抱。

两人从拥抱中抬眼，在近距离确认彼此反应；[一方]低头、[另一方]抬头或踮脚，双方共同靠近并短暂亲吻。亲吻结束后只分开很小的距离，保持[手臂和身体接触状态]。
```

不得从相隔数步直接跳到贴脸，不让道具凭空消失，不写单方突然强吻。

## 十一、交付前检查

- [ ] 单元时长为 5–15 秒。
- [ ] 15 秒单元通常为 36–44 字，有效台词不超过 48 字。
- [ ] 少于 24 字的单元已完成合并检查；没有把"问句+回答+眼神"小回合拆成多个单元。
- [ ] 只有一次关系变化和一条主动作链。
- [ ] 正文以"【全局画质与摄影前置】"块开头，画质前置词完整。
- [ ] 每个 `[Shot N]` 按运镜公式书写：运镜方式、景别、动作链、场景环境（**不写光影微调，人物没动也不写位置**）。
- [ ] Shot 描述里没有 `[0-X秒]`、`[0-3秒]` 之类的时间码；总时长只在单元标题里声明，镜头内节奏交给模型。
- [ ] 每个单元指定了全局光影（光影套件之一），**只在场景段写一次**，Shot 里不重复。
- [ ] Subject、Picture、S 编号一致。
- [ ] 同一张双人图没有虚构 Picture2。
- [ ] 人名全部使用剧本/原作中文原名。
- [ ] 单人图只有 S1且全文没有绑定角色画外音；主要说话人不超过 S1/S2，一次性功能人声符合限制。
- [ ] 场景 Subject 使用人物之后的下一个编号；场景声明 `<Subject N>` 保留。
- [ ] 无独立"人物站位"段；**本段开场站位与姿势写在场景段第一句**，Shot 里只在人物移动时写 from…to…。
- [ ] 每个单元只写本段实际出场的人物 `<Subject>`；未出场角色不写入该段。
- [ ] 每段只上传本段出场人物的参考图，未出场人物的参考图已从上传位撤下；Picture 编号在本段内从 `<Picture 1>` 连续重排，段与段之间编号独立，不沿用全局编号。
- [ ] 每个 `[Shot N]` 独占一行并连续编号。
- [ ] 每条 `says:` 后立即换行接 `<d>[Chinese]……</d>`。
- [ ] 画外音只在两人及以上场景使用，只来自已绑定角色，并使用固定三行格式。
- [ ] 人物移动、道具转移、拥抱和亲吻没有无过程跳变。
- [ ] 图片中的水印和可读文字没有进入生成画面。
- [ ] 固定尾部逐字一致，全文没有背景音乐描述（除非用户明确要求背景音乐并在音频设计块中补充）。
- [ ] 默认只输出中文块（完整、可直接复制到 MiniMax）；用户未明确要求时不输出英文对照。

## 十二、输出语言（默认中文，英文可选）

**默认只输出中文原文块，不输出英文翻译块**：每个成品单元只给出中文原文块（用户实际复制到 MiniMax H3 的内容），严格保持前述各节格式。仅当用户明确要求中英对照时，才在中文块后追加英文翻译块（仅作对照阅读，不参与复制）。

### 12.1 整体结构（仅在用户要求英文对照时使用）

```text
## P0N｜[时长]秒｜[段名]

【中文提示词 / Chinese Prompt（复制此块）】

【全局画质与摄影前置】……（完整中文块，含画质前置、Subject 角色映射、声线、场景声明、全局光影、所有 Shot、<d>[Chinese]台词</d>、固定尾部）

【英文对照 / English Gloss（不复制）】

Subject 1: ...（逐段对应翻译）
...
```

### 12.2 翻译规则

1. **逐段对应**：中文块每一行/每一段，英文块都有对应翻译，顺序一致。
2. **保留结构标签不翻译**：`<Subject1>`、`<Subject 1> (S1) says:`、`<d>[Chinese]`、`</d>`、`<Picture 1>`、`[Shot N]`、`【禁止项】`、`【强制声明】` 等原样保留，只翻译自然语言内容。
3. **人名**：中文块保持中文原名；英文块首次可写译名加括号注释。
4. **台词翻译**：口语化、符合角色声线口吻，不做文学化直译。
5. **声线描述、画质前置、运镜与光影描述**：逐句翻译，保留关键信息。
6. **固定尾部**：英文块翻译为自然英文，中文块仍逐字保留原文。

### 12.3 复制说明

默认输出即为可直接复制的中文块，从"【全局画质与摄影前置】"开始复制到本单元【强制声明】即可。仅在用户要求英文对照时，末尾提示：「复制时只复制【中文提示词】块，英文对照仅供参考。」

### 12.4 例外

- **默认中文单语种输出**：不输出英文对照块，除非用户明确要求中英对照。
- 单元标题、分段大纲、交付说明等管理性内容保持中文即可。
